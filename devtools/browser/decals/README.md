# Floor decal comparison

Run `make dev` and, in another terminal, `npm run dev:tools`. Open
<http://127.0.0.1:5173/devtools/browser/decals.html>.
For an isolated stack on another port, append `?central=http://127.0.0.1:18290`.

Ion Foundry uses its saved decals and the production renderer. Toggle decals,
adjust strength or test blood overlap; compare draw calls at the same camera
position and quality. Actors are static reference poses.

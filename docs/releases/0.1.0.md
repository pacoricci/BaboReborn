# BaboReborn 0.1.0

Initial development release of the browser multiplayer arena shooter inspired by
BaboViolent.

## Included

- Deathmatch, Team Deathmatch, and Capture the Flag.
- A central portal for discovering community servers and rooms.
- Self-hosted community servers with room configuration, bots, and map rotations.
- Container images for central and community hosting.

## Hosting and compatibility

Deploy central and community servers from this release using the image digests
in the attached `images.txt`. See `docs/deployment/DEPLOYMENT.md` for configuration
and backup/restore procedures.

First startup requires an empty PostgreSQL database and fresh central/community
data directories. Both stores initialize their complete version `1` schema.

## Limitations

Operators supply public DNS, TLS certificates, and Google OAuth configuration.

Automated browser coverage uses Chromium; other browsers, devices, and
public-network performance require separate verification.

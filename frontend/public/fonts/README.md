# UI fonts

Self-hosted, unmodified Google Fonts downloads.

- Anton Regular: https://fonts.google.com/specimen/Anton
  (`anton.ttf`, `Anton-OFL.txt`).
- Barlow Condensed Regular and SemiBold:
  https://fonts.google.com/specimen/Barlow+Condensed
  (`barlow-condensed.ttf`, `barlow-condensed-semibold.ttf`, `BarlowCondensed-OFL.txt`).
- Oxanium variable (HUD): https://github.com/google/fonts/tree/main/ofl/oxanium
  (`oxanium.ttf`, `Oxanium-OFL.txt`).

All families are distributed under the included SIL Open Font License 1.1.
